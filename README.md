# 🍩 Donut Shop SQL Project

## 🧁 Overview

This beginner-to-intermediate SQL project simulates a real-world donut shop's database system. I built this project using MySQL to practice querying, relational schema design, joins, subqueries, views, and more. It helps answer business questions like:
- Which donuts are most popular?
- Who are our top customers?
- Are there any products that never sell?

---

## 🗂️ Database Structure

The project includes 3 main tables:
- `customers`: Stores customer details
- `donuts`: Contains donut names and prices
- `orders`: Tracks which customer ordered what donut, in what quantity, and when

An Entity Relationship (ER) diagram is included for clarity.

---

## 🔍 Key SQL Concepts Practiced

✅ **Basic Queries**: `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`  
✅ **Joins**: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`  
✅ **Aggregations**: `GROUP BY`, `HAVING`, `SUM`, `COUNT`, `AVG`, `MAX`, `MIN`  
✅ **Set Operators**: `UNION`, `UNION ALL`  
✅ **Subqueries**: In `WHERE`, `FROM`, and `SELECT` clauses  
✅ **Views**: Created to simplify complex business queries

## 📊 Sample Business Questions Answered
